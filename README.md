# SafeTipin 🛡️

## Women Safety Silent Emergency Assistance System

SafeTipin is a mobile-based women safety application designed to provide discreet emergency assistance and support during potentially unsafe situations.

The system provides multiple ways to trigger an emergency alert and supports communication between users, emergency contacts, volunteers, and police authorities.

## 🚨 Key Features

### Emergency SOS
- Manual SOS activation
- Physical volume-button trigger
- Offline voice-trigger support
- Background safety service
- Emergency evidence recording
- Multi-level emergency notifications

### 🗺️ Guardian Mode
- Destination-based location tracking
- Safety check countdowns
- Incident-aware navigation
- Simulated call feature

### 📍 Incident Reporting
Users can report incidents with:
- Incident type
- Severity
- Description
- Location
- Photo/video evidence

### 👥 Role-Based Access

The system supports different user roles:

- 👩 User
- 🤝 Volunteer
- 👮 Police

Each role has different functionality and access permissions.

### 👮 Police SOS Management
Police users can:
- View SOS requests
- Filter SOS status
- View location and evidence
- Communicate through the system
- Update SOS status
